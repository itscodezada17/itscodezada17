## Featured Project

### NotesApp - Android Notes App

A notes application built with modern Android architecture and backend-backed user-specific note storage.

- Built using **Kotlin** and **Jetpack Compose**
- Based on **MVI Architecture**
- Used **Room** for local database storage
- Used **Dagger2** for dependency injection
- Built self-made APIs for saving and fetching user-specific notes
- Backend built with **Node.js** and **Express.js**
- Used **JWT** for user authentication
